# Knights-Game-
This shows the 1000x1000 pixel pictures created by the Knights game described in this YouTube video: https://youtu.be/UiX4CFIiegM?si=Cq7cE29sca85mEGP

I have included the python file I created to make the images.

A knight move is defined as X moves in one of the 4 cardinal directions, and Y moves perpendicular to that. This is the long and short moves. In normal chess these are 2 and 1.

The pictures are categorized as KM_{long}x{short}.png
